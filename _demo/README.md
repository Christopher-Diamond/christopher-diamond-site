# Demo content from the al-folio template

Kept for reference only. Jekyll does not build underscore folders that are not configured as collections, so nothing here is published.

- `_posts/` — 33 demo blog posts showing al-folio's post features (Distill, maths, code, charts, images, etc.)
- `_news/` — demo news items (inline and long-form)
- `_projects/`, `_books/`, `_teachings/` — demo collection entries
- `_pages/` — demo pages removed from the site: about_einstein, profiles (people), repositories, books (bookshelf), plugins, dropdown (submenus)

To reuse one, copy it back into the matching top-level folder and edit it.
